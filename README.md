# About this project
[![Screenshot][screenshot]](https://trade-a-chest.itch.io/djent-machine)

This repo contains all the C# scripts that were written in order to create Djent Machine.

## Play the game
You can find the Djent Machine by following [this link](https://trade-a-chest.itch.io/djent-machine) which leads to the game's itch.io page.
There you can either play directly from your browser or install the game directly on your computer (Windows only).

## Warning
This repo **DOES NOT** contain :
- Unity project files
- 2D sprites
- Audio files.
